# Files that a person read for licenses that Scripts/check-licenses.sh cannot classify.
#
# NOTICE files name the licenses of code that a package embeds, in free text. Each `notice` line
# records one NOTICE file of a resolved package, under .build, with the SHA-256 digest of the
# reviewed text and the licenses that the text names.
#
# swift-crypto compiles BoringSSL into the binary, and no NOTICE file names it. The `boringssl`
# line records the revision from swift-crypto's hash.txt and the license of that revision.
#
# The check fails on a NOTICE file without a line, on a different digest, on a line whose file is
# gone, and on another BoringSSL revision. Read the new text or revision, confirm that its
# licenses are accepted, and update the line.
#
